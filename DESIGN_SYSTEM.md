# DesignLens Design System & macOS UI Tokens

## Color Palette (macOS Modern Dark Glass Aesthetics)
- **Primary Accent**: `HSL(215, 100%, 60%)` (#2B7FFF - Apple macOS Blue)
- **Secondary Accent**: `HSL(270, 85%, 65%)` (#A855F7 - Vibrant Violet)
- **Success / Match**: `HSL(150, 75%, 45%)` (#10B981 - Emerald Green)
- **Warning / Spacing Delta**: `HSL(38, 92%, 50%)` (#F59E0B - Amber)
- **Error / Font Mismatch**: `HSL(350, 89%, 60%)` (#EF4444 - Rose Red)
- **Background**: `HSL(220, 20%, 10%)` (#12161F - macOS Dark System Background)
- **Surface / Card**: `HSL(220, 18%, 15%)` (#1A202C - Translucent Dark Glass)
- **Border / Divider**: `HSL(220, 15%, 25%)` (#2D3748)

## Typography (San Francisco / Native macOS)
- **Header Large**: 22pt Bold
- **Section Title**: 16pt Semibold
- **Body Text**: 13pt Regular
- **Monospace Code / Dimensions**: 12pt SF Mono Medium
- **Caption / Delta Badge**: 11pt Bold

## Layout & Spacing
- **Corner Radius**: 10px (Cards), 6px (Badges & Buttons)
- **Padding**: 12px (Standard Card), 16px (Container)
- **Shadows**: Subtle dark drop shadow (`0 4px 12px rgba(0,0,0,0.35)`)
